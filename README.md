
# Locentra 🌍

**Precision Location Lookup, Simplified.**

Locentra is a location lookup system designed to help users find geographical locations through address search and location identification. The project aims to make finding places easier and more accurate, with a focus on address lookup and location data.

## ✨ Features

- 🔎 **Location Search** — Search for places using location or address information.
- 📍 **Geographical Identification** — Identify locations using geographical coordinates.
- 🗺️ **Address Lookup** — Support address-based location discovery.
- 🌐 **Location Data** — Work with geographical information such as latitude and longitude.
- 🇳🇬 **Nigeria-Focused** — Designed with Nigerian address lookup use cases in mind.
